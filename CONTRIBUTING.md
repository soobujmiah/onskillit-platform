# Contributing during Phase 0

Use pull requests for public documentation changes. Cite evidence with source and observation date; label statements as observed, confirmed, proposed or unknown. Do not turn an inference into an organizational claim. Update `docs/TRACEABILITY.md` and `docs/READINESS.md` when scope or decisions change. Architecture and business decisions require founding-partner review; application development is outside the current phase.

This repository is public. Never attach private customer/student data, credentials, production exports, unpublished contracts, or third-party content without rights. Do not copy the current site's template or publish suspected security details. Read `AI_ASSISTANT.md` and `SECURITY.md` before contributing.

All eventual builds and tests run on GitHub. Documentation review can inspect files and links without claiming CI verification. No license has been selected, so do not assume permission to reuse the repository's content or future code outside this project.
